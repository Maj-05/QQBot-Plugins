# QQBot-Plugins

这是一个 QQBot / 云崽插件集合仓库，包含多种实用脚本与插件示例。

## 目录说明

- `example/视频解析.js`：B站视频解析插件，支持 BV 号和短链接解析，直接发送视频文件
- `example/pixiv解析.js`：Pixiv 图片检索插件，支持 PID / 标签搜索并返回图片链接和元数据
- `example/`：放置其他插件示例与测试脚本

## 适用环境

- 云崽 / QQBot 相关插件环境
- 需按实际项目结构放入对应插件目录
- 服务器需安装 `ffmpeg`（B站视频解析）

## 使用说明

1. 将需要的插件文件放入对应插件目录
2. 根据环境修改导入路径与消息处理方式
3. 配置 Cookie / API 访问参数
4. 启动机器人并测试功能

## 备注

- 某些插件依赖外部接口，可能受网站风控、Cookie 失效或网络限制影响
- 仅用于学习、开发和本地测试用途
