# hunt-plugin

云崽（Yunzai）插件：猎杀对决 Hunt: Showdown 1896 玩家战绩查询。

数据来源：bayouledger.com，纯本地抓取解析，不依赖任何 AI 接口。

## 安装

把整个 `hunt-plugin` 目录放进 Yunzai 的 `plugins/` 下，重启即可。

## 用法

| 指令 | 说明 |
| --- | --- |
| `#猎杀 <名字或SteamID>` | 查询指定猎人战绩 |
| `#猎杀战绩 <名字>` | 同上 |
| `#猎杀排行` | 查看 MMR 排行榜前十 |

## 输出内容

- MMR / KDA / KD
- 击杀、死亡、赏金
- 游玩时长
- 打法原型（顶级掠食者、侦察兵等）
- 名册排名与击杀排名

## 文件说明

- `index.js`：云崽插件入口，正则匹配指令
- `hunt_query.js`：请求与数据格式化
- `hunt_core.js`：HTML 内嵌对象解析工具

## 备注

- 站点数据为第三方统计，仅供参考
- 抓取失败时会返回提示，不影响机器人运行
